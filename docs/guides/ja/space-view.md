`@johnmorrisdotca/wakusei-planets/space/element` は `<wakusei-space>` を登録します。地球・月・太陽・ほかの7つの惑星と、冥王星をふくむ9つの準惑星と5つの小天体 (ベスタ、パラス、ケイロン、ポルス、ハレー彗星) を、指定した日時の場所に置き、パッケージが知っているすべての衛星を、それぞれの惑星のまわりに置いて、three.js で描きます。ページで共有する WebGL コンテキストを1つだけ使います。月の満ち欠けも、地球の昼の側も、表ではなく光から決まります。地球から太陽系ぜんぶまでズームでき、時間は前にも後ろにも進められます。

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>The Earth, the Moon and the planets on 2 November 2026</title>
    <script type="module" src="https://cdn.jsdelivr.net/npm/@johnmorrisdotca/wakusei-planets/space/element/+esm"></script>
  </head>
  <body>
    <wakusei-space time="2026-11-02T14:00Z" speed="0" look="realistic" style="width: 420px"></wakusei-space>
  </body>
</html>
```

three が必要です (任意の peer 依存)。表面の絵は、jsDelivr か、`texture-base` で指定したフォルダから読み込みます。この表示では、表面の絵を持つ天体は、どちらの見た目 (`look="realistic"` と `look="painted"`) でもその絵で描かれ、月も火星も同じです。カメラが近づくと、細かい地図のタイルも加わります。絵のない天体 (フォボス、ダイモス、天王星の衛星) は、数字から陰影をつけて描きます。自分の three.js のシーンで同じにするには、painter の context に `mapped: true` を渡します。天体はすべてこのパッケージの描画部品で描くので、`<wakusei-body>` と同じ見た目です ([自分の three.js シーンで使う](in-your-own-scene.md))。

## 位置

位置はこのパッケージ自前のモデルだけで求めます。太陽と惑星は VSOP87B、冥王星は JPL Horizons に合わせた表、月は ELP2000 です。J2000 の赤道座標での幾何学的な位置で、光行差や章動は入れていません。入れても約20秒角しか動かず、この縮尺ではピクセルの何分の一にもなりません。計算だけの関数は `@johnmorrisdotca/wakusei-planets/space` にあり、サーバーでも使えます。

```ts
import { frameAt, placeAround, placeSun } from "@johnmorrisdotca/wakusei-planets/space";

const frame = frameAt(Date.UTC(2026, 10, 2, 14));
const sun = placeSun("compressed", frame.sun);
const [x, y, z] = placeAround("compressed", sun, [frame.planets.mars[0] - frame.sun[0], frame.planets.mars[1] - frame.sun[1], frame.planets.mars[2] - frame.sun[2]]);
console.log(Math.hypot(x - sun[0], y - sun[1], z - sun[2]).toFixed(0));
```

`frameAt(ms)` は、地球の中心から見た太陽・月・惑星の位置 (天文単位) です。テスト用の別ライブラリ astronomy-engine と比べて、太陽と月は100分の1度以内、惑星は数100分の1度以内で合います。`createTrack(stepMs)` は、本当に計算した2つの時刻のあいだを補います。1秒に1日進めても、計算は1秒に約2回で、描くたびに計算し直すことはありません。

## 縮尺は二通り

宇宙はほとんど空っぽなので、本当の縮尺ではほとんど真っ暗で、天体は点に見えます。この要素は両方を持っていて、`scale` で切り替えます。初期値は本当の距離 (`true`) です。

| `scale` | 距離 | 大きさ |
|---|---|---|
| `true` (初期値) | 距離も大きさも本物で、地球の赤道半径が1です | 本物の大きさ。惑星は点のように小さく、太陽は光る点です。半径が画面で4CSSピクセルに満たない天体には、名前に加えて、その場所のまわりに輪も描くので、どの惑星も見失いません |
| `compressed` | 向きはすべて本物です。月は地球の半径の3.5倍の所に (本当は60倍)、太陽は70倍の所に (本当は23,500倍) 描きます。惑星は太陽から本物の向きに、70に天文単位の距離の0.45乗をかけた半径の所へ置くので、地球の軌道が70、海王星が約320です (本当は30倍)。太陽・天体・軌道の線は同じ一つの変換 (`placeBodies`、`orbitLine`) を通るので、地球もふくめ、どの天体も自分の軌道の線の上にいます。惑星の衛星は、本当の距離だとなりの惑星の軌道をこえてしまうときは近くに描きます (`moonDistance`)。いちばん遠い衛星はすき間の3分の1、ほかは順番をそのままに | 太陽が5、月が0.273 (地球と並べたときの本当の大きさ。地球の4分の1ほど)、惑星が0.4から1.8 (地球の半径を1として。実際より大きめ) |

いま使っている縮尺の名前は、要素の画面にいつも表示されます。「本当の距離」か「距離を縮めて表示」です (`lang="ja"` なら日本語になり、`space.scaleNames = { true: "..." }` でページ独自の言葉にでき、`::part(scale)` で行の見た目を変えられます)。以前の初期値のままにしたいページは `scale="compressed"` と書きます。`space.placeOf(id)` は、天体がいま画面のどこにあるか (要素の中での中心と半径、CSSピクセル) を返します。

## 時間

`time` は ISO 形式の日時 (`2026-11-02T14:00Z`) か `now` です。`speed` は1秒に進むゲーム内の秒数です。`1` は実際と同じ、`0` は止める、`3600` は1秒で1時間、`86400` は1秒で1日、マイナスは逆戻りです。`time` を変えると、カメラは地面の同じ場所をもう一度向きます。地球は本物の自転で回り、月はいつも同じ面を地球に向け、各惑星は太陽の光を受けるので、金星は三日月に、月は半月になります。

`light="lit"` にすると、カメラの側から昼の光が当たっているように、すべての天体を照らします (太陽は自分で光ります)。夜の側を見ても真っ黒になりません。どちらでも、天体は本当の位置のままです。

## ズーム、天体を見る、名前

この要素は、ドラッグ、ピンチ、Ctrl とホイール、キーを自分で受けます ([ズームと移動](zoom-and-pan.md))。範囲は100万分の1 (太陽系ぜんぶが見えるところまでカメラを引く) から3.6倍までです。カメラは、見ている天体の半径の `4.1 / zoom` 倍の所にいます。ズーム1では、表示がどんな形でも、天体ぜんたいが、短いほうの辺の約8割の大きさで、まわりに余白をつけて見えます。上限の3.6倍は、地図のタイルがいちばん細かく見えるところです。カメラは表面から1.05半径より近づかないので、約3.9を超えても何も動きません。3.6倍では、表面は地図のタイルがいちばん細かいところまでくっきり見えます (タイルがあるのは、地球と、`painted` の見た目の火星と月です。[近づくズームと地図のタイル](close-zoom.md))。タイルは、カメラがそこまで近づいたときだけ、見えている部分ぶんを取ります。ボタンがほしいときは、ファミリーの `<kazoku-view-controls for="space">` を横に置きます。バーも同じ範囲を読みます。`zoom-min` と `zoom-max` はどちらにつけても範囲が変わり、`controls="none"` で要素自身の手を外せます。`space.zoomFor("moon" | "sun" | "inner" | "solar-system" | "earth" | "jupiter-moons")` は、いまの縮尺と時刻で、空のその部分が収まるズームを返します (名前は大文字でも小文字でも構いません。プリセットでない名前には、見ている天体ぜんたいが収まるズーム1を返します)。`space.controller.set({ zoom })` (バーがあるときは `controls.controller.set({ zoom }, true, "jump")`) でそこへ行きます。`space.setView(コントロールの値)` は、カメラを天体のまわりで回します (`roll` は画面を時計まわりに回し、`panX` と `panY` は、絵の中のすべてをちょうどそのCSSピクセル分、右と下を正として、奥行きに関係なく動かします)。カメラは星に固定されているので、時間が進むと地球はカメラの下で回ります。

`space.body = "jupiter"` で、カメラをその天体に向けます。大文字でも小文字でも、英語でも日本語でも、この表示にある天体ならどれでも使えます (`earth`、`sun`、`moon`、`mercury` から `neptune`、`pluto`、それに `titan` のような惑星の衛星)。天体でない名前を入れても何も変わりません。各天体の横の名前はボタンです (Tab と Enter)。ドラッグではない押し方で天体を押すと、`wakusei-body-click` が `{ id, name, kind, host, radiusKm, distanceKm }` つきで発火します (キーボードでは `wakusei-body-focus`)。同じ値は `space.bodyInfo(id)` でも得られます。`space.bodyNames = { mars: "火星" }` や `lang="ja"` で表示する言葉を変えられます。

名前は重なりません。2つの名前の枠が重なるときは、大事なほうだけを出し、出さない名前は輪も出しません。優先は、見ている天体、太陽、惑星、月の順で、同じ順なら画面で大きいほうが残ります。衛星は惑星に、惑星は太陽に場所をゆずり、ズームインすると名前が戻ります。`@johnmorrisdotca/wakusei-planets/space` の `chooseLabels(boxes)` は、同じ決まりを、ふつうの四角形の一覧に当てはめられます。

惑星が数ピクセルの大きさになると、そのまわりに近い衛星が現れます。位置はこのパッケージの衛星モデルが出します (`zoomFor("jupiter-moons")`)。地球と惑星が太陽のまわりを回る道と、月が地球のまわりを回る道は、`orbits="off"` にしない限り描きます。どの線も天体と同じ変換を通るので、どちらの縮尺でも、天体は自分の線の上にいます。`stats.orbits` は、描いた線と、各天体が自分の線からどれだけ離れているか (線の半径に対する割合。線の上なら0.01未満) を返します。月の線は、月がいる場所から恒星月1つぶんの道で、時計が数日進むたびに計算し直します。点は `moonOrbit(ms)` で得られます。

## すべての天体

この表示は、パッケージが知っているすべての天体、52個を出します。太陽、8つの惑星、9つの準惑星 (冥王星、ケレス、オルクス、ハウメア、クワオアー、マケマケ、ゴンゴン、エリス、セドナ)、5つの小天体 (小惑星のベスタとパラス、ケンタウルス族のケイロンとポルス、ハレー彗星)、29の衛星です。`/space/element` の `SPACE_BODIES` は、シーンの中心に置く24個の一覧で (準惑星は接触軌道要素から。2026年の前後数年ぶんで有効です。小天体は Horizons に合わせた表から、1秒角以内で置きます。表は表示が自分で読み込みます)、衛星はどれも本当の軌道で、それぞれの惑星のまわりに置きます。どれも表示の中心にでき、行き先に選べ、順にめぐれ、乗って見られます (`space.ride("ceres")`、`space.ride("titan")`、`space.ride("vanth")`)。画面で小さすぎて見えない準惑星や小天体 (半径が半ピクセルに満たないもの。実際の縮尺では、どの小惑星も彗星もこれに当たります) は描かず、名前と輪だけを出し、見に行くまで絵も作りません。衛星は、惑星が数ピクセルの大きさになると描きます。`orbits` がオンなら、準惑星と小天体の軌道の線も出ます (ハレー彗星の線は、海王星の距離までのびる細長い楕円で、太陽のそばで急に曲がります)。`space.zoomFor("mars-moons")` (`jupiter`、`saturn`、`uranus`、`neptune`、`pluto`、`orcus`、`haumea`、`eris` も) は、惑星とその近い衛星が収まるズームを返します。

デモでは、3回のクリックで順に選びます。種類 (太陽と惑星、準惑星、小天体、衛星)、衛星ならそれが回る惑星、そして天体です。横には名前 (英語でも日本語でも) でさがす欄があり、衛星のある惑星には「衛星もいっしょに」ボタンが出ます。自分の選び方を作るときは、`space.bodyList()` がそのデータです。

## 天体へ行く、天体をめぐる

天体かその名前を最初に押すと、その天体が選ばれます。`wakusei-body-click` と同じ内容 (detail) を持つ `wakusei-body-select` が発火し (ページのカードに使えます)、`space.selected` で読めますが、表示は動きません。選ばれた天体をもう一度押すか、`space.goTo("saturn")` を呼ぶと、その天体が表示の中心になります。カメラは約1秒でそこへ滑るように動き (動きを減らす設定の人や `{ smooth: false }` のときは一瞬で移ります)、ズームは1に戻って天体ぜんたいが見え (`{ zoom }` で別の値も指定できます)、時間が進んでもその天体を追います。押しても、ほかの場所へ飛ぶことはありません。すでに中心にある天体を押しても何も起こりません。`goTo` は、そこへ行けるかどうかを返します。`<kazoku-view-controls>` を要素に結びつけているときは、ズームの状態をバーが持つので、イベントが運ぶ値をページが `controls.controller.set({ zoom }, true, "jump")` で反映します。

めぐる順番は一つに決まっています。太陽、水星、金星、地球、月、火星、フォボス、ダイモス、木星とその衛星、と外へ進み、各惑星の次にその衛星が近い順に来ます (全体は `/space` の `HOP_ORDER` です)。`space.next()` と `space.previous()` は、次の天体と前の天体へ行き、最後からは太陽にもどります。どちらも、行った先の `BodyInfo` を返します。中心が変わるたびに `wakusei-hop` が `{ current, previous, next }` (それぞれ `BodyInfo`。`goTo` やめぐる操作がズームを求めたときは `zoom` も) つきで発火するので、矢印を2つ置いて、それぞれの行き先の名前を見せられます。`space.hopper` では、同じ内容がいつでも読めます。`space.bodyList()` はジャンプ用の一覧で、行けるすべての天体を順番に、種類 (`kind`: `star`、`planet`、`dwarf-planet`、`moon`) と、衛星なら `host` つきで返します。`/space` の `findBody("Saturn")` と `findBody("土星")` は、人が入力した言葉から天体を読み取ります。

## 天体を離れるとき

ほかの天体へ向かう移動 (`goTo`、順にめぐる `next` と `previous`、乗って見る) は、どれもゆっくりした出だしから始まります。離れていくところが見えるように、最初の5分の1の道のりに約0.5秒かけ、そこから速くなって、行き先に落ち着きます。どう向かうかは、名前のついたトランジションで決めます。属性とプロパティの `transition` で選ぶか、1回の移動だけなら `space.goTo("jupiter", { transition: "look-back" })` のように指定します。

| 名前 | 動き |
|---|---|
| `direct` | 初期値。ゆっくりした出だしのあと、行き先へまっすぐ向かいます。行き先は見えたまま、だんだん大きくなります。 |
| `look-back` | 離れる天体を見たままうしろへ引いていき、道のりの終わりのほうで行き先へ向きを変えます。 |
| `auto` | 出発するとき行き先が画面に入っているなら `direct`、入っていないなら `look-back` です (名前の表示がオンのときだけ働きます。天体が画面のどこにあるかは、名前からわかるためです)。 |
| `cut` | 滑らせずに、一瞬で行き先の画面になります。動きを減らす設定の人には、いつもこれが使われます。 |

2つの設定で調整できます。どちらもミリ秒です。`launch` (属性。プロパティは `space.launchMs`) は、ゆっくりした出だしの長さで、初期値は500です (0なら速い移動で、長くすると、そのぶん移動も長くなります)。`turn` (属性。プロパティは `space.turnMs`) は、`look-back` の終わりの向きの変更にかける時間で、初期値は700です。`TRANSITIONS` は名前の一覧、`glideProgress` と `turnProgress` は動きの曲線で、曲線を自分で描きたいページ向けです。

```ts
import { glideDuration, glideProgress, TRANSITIONS } from "@johnmorrisdotca/wakusei-planets/space";

console.log(TRANSITIONS.join(", "));
// 出だしが終わるまでに、道のりの約5分の1を進みます
console.log(Math.round(glideDuration(500)), "ms in all,", glideProgress(500, 500).toFixed(2), "of the way after the launch");
```

## 全画面

`immersive` (属性、または `space.immersive`) をつけると、要素は全画面の表示になります。入れ物の大きさに、どんな形でもぴったり広がり (`width: 100%; height: 100%`。ページが幅と高さを決めれば、属性なしでも同じです)、ホイールだけで拡大縮小し、どこをドラッグしても (タッチのドラッグも) 回ります。ページはスクロールしません。`immersive` がないときは kazoku-ui の決まりのままで、Ctrl、Command、Alt のどれかを押しながらホイールを回すと拡大縮小し、ホイールだけならページがスクロールします。ズーム1では、見ている天体は表示の短いほうの辺の約8割の大きさで、まわりに約5分の1の余白が残るので、縦長の窓でも横長の窓でも切れません (土星は環ごと収まります)。`zoom-min` まで引くと、カメラは太陽系ぜんぶが見えるところまで下がります。

```html
<style>
  html, body { margin: 0; height: 100%; background: #04060c; }
  wakusei-space { position: fixed; inset: 0; }
</style>
<wakusei-space immersive time="now" speed="3600"></wakusei-space>
```

ページ [space-full.html](https://johnmorrisdotca.github.io/wakusei-planets/space-full.html) がこの形で、下にファミリーの表示コントロールが重なります。`@johnmorrisdotca/kazoku-ui/testing` の `checkGestures` は、このページで通ります。例外は1つだけで、ホイールだけでの移動 (パン) です。このページではホイールだけで拡大縮小するためです。

## 進む向きを示す矢印とヘルプモード

`orbits` がオンのとき、各軌道の線に沿って小さな矢じりが2つあり、天体が回る向きを指します (月の線にもあります)。向きを示すには2つで足り、それ以上は見づらくなるだけです。矢じりの数は `arrows` (属性とプロパティ。`space.arrows = 3`) で決めます。初期値は2、最大は4で、0なら矢じりは出ません。それ以外の値は、この範囲の整数に直されます (値を読む関数は `arrowCount` で、初期値と最大値は `ARROWS_PER_ORBIT` と `MAX_ARROWS_PER_ORBIT` です)。軌道の長い天体 (セドナ、エリス、ゴンゴン、ハレー彗星) の線は、時間の等間隔ではなく、楕円に沿った等間隔で区切って描くので、太陽の近くの急な曲がりが、角ばった直線ではなく、なめらかな曲線になります。矢じりの長さはズームに関係なく約9CSSピクセルなので、太陽系ぜんたいから月まで見え、天体をかくすほど太くなることはなく、天体のすぐそばには出ません。天体に近づいて、円盤の幅が数十ピクセルほどになると、軌道の線は真横から見えて、天体を横切る長い直線の引っかき傷のようになります。そこで、その天体と同じ系の線だけを描きます (月に近づいたときは月の線と地球の線、地球に近づいたときは地球の線と月の線)。その線も、天体から半径の約12倍以内の部分は薄くなって消えるので、円盤を横切る線は1本も描かれません。省いた線は `stats.orbits.hidden` で分かります。矢印は、天体が本当に進む向きを示すので、時間を逆に進めても変わりません。そのときは、天体が矢印と反対に動きます。`/space` の `arrowSites(line)` と `chevron(...)` が、場所と形です。`stats.orbits` と `stats.arrows` で、各矢印の場所と向きが分かります。

`help` (属性、または `space.help`。初期値はオフ) はヘルプモードで、見ている天体に、軸にそった線と、回る向きを示す曲がった矢印を、天体の上に重ねて描きます。矢印は、天体が本当に回る軸のまわりを、右ねじの向きにまわります。その軸は、`spinAxis(id, ms)` が本初子午線の動きから求めます。地球、火星、木星やほとんどの天体は軸が北極の向きで、金星と天王星は逆まわりなので、北極と反対向きです。横だおしの天王星は、軸が黄道にほぼそって見えます。いつも同じ面を惑星に向ける衛星は、軌道を1周するあいだに1回まわり、公転と同じ向きです。デモでは、ヘッダーのファミリー共通の「説明」スイッチと結んでいます。`stats.help` は、どの天体か、その軸、描いた矢印がまわる軸を返します。

## プロパティ、イベント、stats

属性は `center` (`"lon,lat"`)、`time`、`speed`、`scale` (`true` か `compressed`。初期値は `true`)、`help` (ヘルプモード。初期値はオフ)、`look` (`realistic` か `painted`)、`light`、`labels` と `orbits` (`off` で隠す)、`lang`、`texture-base`、`texture-far-base`、`max-texture`、`tiles` (細かい地図のタイルの場所。`off` でなし) です。イベントは `wakusei-view` (表示が変わった: `yaw`、`tilt`、`zoom`)、`wakusei-ready`、`wakusei-unavailable`、`wakusei-state`、`wakusei-timechange` (日付が変わった: 時間が進む間は1秒に4回まで、止まったときに1回、`{ time, running }`)、`wakusei-time` (時計が1ステップ進むたび)、`wakusei-body-click`、`wakusei-body-focus` です。`stats` には `state`、`draws`、`contexts`、`canvas`、`distance`、`time`、`lookups`、`camera`、`bodies`、`tiles` があります。

## 乗って見る

`space.ride("moon")`、`space.ride("io")`、`space.ride({ at })` で、カメラを動く点に乗せ、その点が回る天体を見ます。詳しくは [乗って見る](ride-along.md) をどうぞ。

## 負荷の上限

このパッケージの3D表示と同じ決まりを守り、`pnpm test:freeze` で確かめています。共有レンダラーで WebGL コンテキストは1つ、キャンバスは1辺4096ピクセル以内かつ600万ピクセル以内、止まっている間は何も描かず、1秒に30フレームまで、実際の時間なら1分に1回だけ描き直し、画面の外では描かず、要素を外せばすべて解放し、失われたコンテキストは自動で戻します。
