`<wakusei-surface>` は、高さを実測してある場所の月面に視点を置きます。地面は実際の表面のモデルから描かれ、表示している時刻の本当の位置にある太陽に照らされ、地面自身の影が落ち、黒い空には本当の位置に本当の満ち欠けの地球が浮かびます。いまあるのは1か所、アポロ17号の着陸地点（タウルス・リットロー）だけです。幅数キロの谷が、高さ2キロの山に挟まれています。

```ts no-run
import "@johnmorrisdotca/wakusei-planets/surface/element";

const view = document.createElement("wakusei-surface");
view.setAttribute("site", "apollo-17");
view.setAttribute("time", "1972-12-11T19:54Z"); // 着陸の瞬間：太陽は高度13度、影が長い
view.setAttribute("tiles", "https://johnmorrisdotca.github.io/wakusei-planets/tiles/");
document.body.append(view);
```

## 操作

ドラッグで向きを変えます。W・A・S・D（または矢印キー）で歩きます。速さは秒速1.4メートルで、目の高さは地面の起伏（クレーターを含む）に合わせて上下します。Q と E で回り、+ と - でズームし、Ctrl を押しながらホイールを回すかピンチするとズームします。ズームは視野角で、画面の上から下まで8度から100度です。何も変わらないときは描きません。キーを押している間も、1秒に30回までです。

属性は `site`、`time`（ISO の日時、1970年からのミリ秒、または `now`。省略すると着陸の瞬間）、`heading`（北から時計回りの度数）、`pitch`、`fov`、`tiles`（高さのタイルの置き場所）、`lang` です。試すためのものとして `shadows="off"`、`detail="off"`、`exposure` もあります。

## 地面の出どころ

高さのタイルは `scripts/make-moon-terrain.py` が、NASA の公有データから作ります（NOTICE.md に、各ファイルの出どころと求められる表記を書いています）。使うのは、月周回機 LRO の狭角カメラによる5メートル間隔の高さモデルと、それより外側のためのレーザー高度計の全球地図です。前者はレーザー高度計の測定に結びつけてあるので、高さはおよそ1メートル、位置はおよそ10メートルの精度です。タイルは4段階（サンプル間隔 5・20・80・480メートル）で、256サンプル四方に切り、高さは16ビットで画像として持ちます（高さの2バイトを2つの色にしているのは、ブラウザが16ビット画像をそのまま読めないためです）。タイルはどのパッケージにもリポジトリにも入っていません。Pages のワークフローが作り、デモの隣で配ります。要素は既定でそこを見ます。

地平線は実測です。モデルは地点から29キロまで届き、そこから先は全球地図で、80キロ先の山も本当の位置にあります。月の丸みも引いてあります（地面は1キロで29センチ落ち、目の高さから見た平地の地平線は2.5キロです）。

地面の絵は、狭角カメラ自身のモザイク画像から、高さによる陰影を割り算で取り除いたものです。スクリプトがモザイクを照らしていた太陽（方位角と仰角）を、写っている地形の高さに合わせて求め、その陰影を取り除いて、地面そのものの明暗だけを残します。その絵を表示時刻の太陽でもう一度照らすので、2つの光が重なることはありません。

## 光と影

太陽と地球は、このパッケージ自身の暦から求めます。`moonSky(lat, lon, time)` は、太陽と地球の方位と高度、大きさ、そして地球の明るい部分の割合を返します。地球の割合は月の満ち欠けの逆です（満月のときの地球は新月です）。地面の光は、月の砂が従う Lommel-Seeliger の法則で（太陽側で明るく、影の側では暗い）、空気がないので霞はなく、空は黒です。

```ts
import { moonSky } from "@johnmorrisdotca/wakusei-planets/surface";

const sky = moonSky(20.1911, 30.7723, Date.UTC(1972, 11, 11, 19, 54));
console.log(`太陽は高度${sky.sun.altitude.toFixed(0)}度、地球は高度${sky.earth.altitude.toFixed(0)}度で${(100 * sky.earthIllumination).toFixed(0)}%が明るい`);
```

影ははっきりしていて、各点から太陽に向かって同じ高さのデータの上をたどって求めます（地平線の角度の追跡）。シャドウマップでは、小石の影と山の影を1枚で扱えませんが、この方法なら追加の描画なしで両方扱えます。点の近くでは作ったクレーターも追跡に含めるので、クレーターの縁はその内側にくっきりした影を落とします。

## 作ったもので、実測ではないもの

5メートルの格子より細かいものについてはデータがないので、作ります。0.5メートルから20メートルの小さなクレーター（月の大きさ頻度分布に従い、小さいものが多く大きいものは少なく、新しいものは幅の5分の1の深さ、古いものは浅く、縁はやわらか）、砂塵の細かいざらつき（法線に加えます）、10センチから1.5メートルの岩（新しいクレーターの縁の近くに多め）です。すべて場所から決まる乱数で作るので、同じ場所はいつも同じで、遠くでは消えるのでちらつきません。**作ったもので、実測ではありません**。画面の地面の下にもそう書きます。`detail="off"` にすると実測の地面だけを見られます。目の高さも作ったクレーターに従うので、クレーターに踏み込めば下がります。

## かかる負荷

描くのは何かが変わったとき（向き、歩み、時刻）だけで、止まっているときや見えていないときは何も描きません。キーを押している間も1秒に30回までです。キャンバスは共有レンダラーのもので、ページ全体で WebGL コンテキストは1つ、600万画素以内、1辺4096以内です。1回の描画の負荷はフラグメントシェーダーにかかり、画素ごとの追跡と数個のクレーターのセルを調べます。グラフィックスカードならミリ秒単位ですが、ソフトウェア描画（テストで使います）では小さな画面でも数秒かかるので、テストは小さな画面で行います。最初の表示で約8MBのタイルを取得します。

## パッケージが出すもの

`WakuseiSurface`（要素）と `SURFACE_SITES` は立てる場所を、`moonSky` と `localFrame` は空を、`forward`、`viewProjection`、`clampLook`、`stepOver` はカメラを、`loadTerrain`、`tileAddress`、`groundAt`、`sampleLevel`、`decodeHeight` は高さを、`madeGround`、`craterIn`、`rocksAround`、`rockMesh` は作った細部を表します。細部の式はシェーダーと同じで、1か所（`src/surface/detail.ts`）に書き、テストで両者を揃えています。
