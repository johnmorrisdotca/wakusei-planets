`/kids` は、子どもがよくする2つの質問に答えます。「火星だと体重はどれくらい?」と「木星だと何さい?」です。ブラウザなしでどこでも動き、自分の時計も持ちません。日付は引数で渡します。デモの[こどものページ](https://johnmorrisdotca.github.io/wakusei-planets/kids.html)では、大きくてかわいいカードで見られます。英語と日本語に対応しています。

```ts
import { ageOn, nextBirthdayOn, weightOn } from "@johnmorrisdotca/wakusei-planets/kids";

const born = Date.UTC(2016, 10, 8);
const today = Date.UTC(2026, 10, 8);

console.log(weightOn("moon", 30).toFixed(1), "kg on the Moon");
console.log(weightOn("jupiter", 30).toFixed(1), "kg at Jupiter's cloud tops");
console.log(ageOn("earth", born, today)?.wholeYears, "years on the Earth");
console.log(ageOn("mars", born, today)?.years.toFixed(1), "years on Mars");
console.log(nextBirthdayOn("mars", born, today)?.date.toISOString().slice(0, 10), "is the next Mars birthday");
```

## 体重

`weightOn(world, weight)` は、その世界での体重を、渡した単位のまま返します。キロを入れればキロ、ポンドを入れればポンドです。体重計の数字は変わっても、あなたの質量は変わりません。変わるのは引っぱる力です。地球の体重計に、その世界で乗ったときの数字です。

引っぱる力は表面の重力で、GMを半径の2乗でわって出します。赤道での値で、その世界の自転は入れません。地球の重力と同じやりかたで出した値の何倍かで表すので、地球はちょうど1です。`surfaceGravity(world)` は、メートル毎秒毎秒 (`metresPerSecondSquared`)、地球の何倍か (`relativeToEarth`)、どこではかったか (`surface`)、出どころ (`source`) を返します。

| 世界 | 引っぱる力 (地球 = 1) | 表面の重力、m/s² |
|---|---|---|
| 太陽 | 28.0 | 274 |
| 水星 | 0.38 | 3.70 |
| 金星 | 0.91 | 8.87 |
| 地球 | 1 | 9.80 |
| 月 | 0.17 | 1.62 |
| 火星 | 0.38 | 3.71 |
| 木星 | 2.53 | 24.8 |
| 土星 | 1.07 | 10.4 |
| 天王星 | 0.91 | 8.87 |
| 海王星 | 1.14 | 11.1 |
| 冥王星 | 0.06 | 0.62 |
| イオ | 0.18 | 1.80 |
| タイタン | 0.14 | 1.35 |

はかる場所は、惑星や衛星では表面、太陽では目に見える表面 (光球) です。木星、土星、天王星、海王星では、**雲の上、気圧が1バールのところ**です。地球の海面と同じ気圧です。ガスの惑星には、立てる地面がないからです。`surface` には `"surface"`、`"photosphere"`、`"cloud-tops"` のどれかが入ります。

出どころは世界ごとに決まっています。太陽、水星、金星のGMは、NASAの惑星ファクトシート (https://nssdc.gsfc.nasa.gov/planetary/factsheet/) です。地球、火星、木星、土星、天王星、海王星、冥王星と、すべての衛星のGMは、JPLの Planetary Satellite Physical Parameters (https://ssd.jpl.nasa.gov/sats/phys_par/) です。半径はIAUとNASAの値で、`BODIES` と同じです。これらは `journeyStop` がすでに持っている数字です。どれを使ったかは、各世界の `source` に書いてあります。値は、NASAが発表している表面重力と1パーセント以内で合います (テストで確かめています)。質量の発表がない天体 (ネレイドと、冥王星以外の準惑星) は、ここでは世界に入れていないので、`WORLD_IDS` にもありません。

## 年れい

`ageOn(world, birth, now)` は、そこでの年れいを、その世界の年と日で返します。

| 項目 | 意味 |
|---|---|
| `years` | その世界の年での年れいです。1年のうちの進んだ分も入ります (5.3は、5年とちょっと)。 |
| `wholeYears` | 整数の年です。子どもが言う年れいです。 |
| `days` | そこで過ごした日数です。1日は、その世界の太陽日です。 |
| `yearDays` | その世界の1年の長さです。地球の日数で表します。 |
| `dayHours` | その世界の太陽日の長さです。地球の時間で表します。 |

世界の**1年**は公転周期で、NASAの惑星ファクトシートの値です。水星は87.969日、金星は224.701日、火星は686.98日、木星は4,332.589日、土星は10,759.22日、天王星は30,685.4日、海王星は60,189日、冥王星は90,560日です。衛星は惑星といっしょに太陽のまわりを回るので、**衛星の1年は、その惑星の1年**です。月の1年は地球の1年、タイタンの1年は土星の1年です。地球と月では、年をカレンダーのたんじょう日で数えるので、`wholeYears` は本当の年れいになり、10さいの子は、その日にちょうど10になります。

世界の**1日**は太陽日で、正午から次の正午までです。1 / (1 / 自転周期 − 1 / 1年) で出します。自転周期はIAUの値で、金星、天王星、冥王星では逆向きです。水星は4,222時間 (地球の176日)、金星は2,802時間、地球はちょうど24時間、火星は24.66時間、木星は9.93時間、冥王星は153時間、月は708.7時間 (地球の29.5日) です。いつも同じ面を惑星に向けている衛星の太陽日は、その公転とほぼ同じ長さです。

太陽には数えられる年も日もないので、`ageOn("sun", ...)` は `null` です。冥王星の小さな衛星のニクスとヒドラは、決まった自転がなく、ふらふら回っているので、`days` と `dayHours` は `null` です (年は冥王星の年です)。

## 次のたんじょう日

`nextBirthdayOn(world, birth, now)` は、`now` 以後で、あなたが生まれた日にその世界があった場所へ、はじめてもどる時刻を返します。年は、生まれたときから数えます。`date`、`turns` (そこで何さいになるか)、`inEarthDays` (その日なら0) が入っています。地球と月では、カレンダーのたんじょう日です。2月29日は、29日のない年には2月28日にします。太陽は `null` です。

## 日付

たんじょう日は、カレンダーの日付なので、たんじょう日と今日は、**その日のUTCの午前0時**で渡します。`Date` でもミリ秒でもかまいません。`Date.UTC(2016, 10, 8)` は、2016年11月8日です。ページでは、日付の欄と今日の日付 (そのパソコンの日付) を、デモと同じようにして変えます。`now` より後のたんじょう日や、日付でないものは、`RangeError` になります。

```ts
import { WORLD_IDS, ageOn } from "@johnmorrisdotca/wakusei-planets/kids";

const now = new Date();
const today = Date.UTC(now.getFullYear(), now.getMonth(), now.getDate());
const [year, month, day] = "2016-11-08".split("-").map(Number);
console.log(WORLD_IDS.length, ageOn("venus", Date.UTC(year!, month! - 1, day!), today)?.wholeYears);
```

## こどものページ

デモの `kids.html` には、太陽、それぞれの惑星、冥王星、月、大きな衛星 (イオ、エウロパ、ガニメデ、カリスト、タイタン、トリトン) の、大きなカードがあります。カードには、線の絵 (`lineSvg`)、大きくて丸い文字の名前、引っぱる力が地球の何倍か、そこでの体重、年と日で数えた年れい、次のたんじょう日が出ます。体重はキロかポンドで、たんじょう日といっしょに入れます。英語と日本語は、ひとつずつ切りかえます。日本語は、ふだんの言葉です。欄とボタンの高さは56ピクセルです。

**何も保存しません。** 体重とたんじょう日は、2つの欄にだけあります。`localStorage` にも、クッキーにも、アドレスにも入りません。ページを読みこみなおすと、空になります。自分のページでも、子どものたんじょう日は同じようにしてください。
