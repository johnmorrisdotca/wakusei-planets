パッケージはまだ0.xなので、マイナーバージョンで動作が変わることがあります。完全な一覧は [CHANGELOG.md](../../../CHANGELOG.md) にあります。このページでは、対応が必要なものをまとめます。

## 0.4 から 0.5 へ

変更は要りません。0.5 では `@johnmorrisdotca/wakusei-planets/painter` が加わりました。`painter.make(three, "Jupiter", { look, invalidate, ratio })` は、太陽、惑星、冥王星、衛星を半径1のオブジェクトとして、自分の遠近カメラのシーンに、陰影つきまたは地図つきの見た目で渡します。`orientation(id, ms)` と `moonOffset(id, ms)` は、同じ座標軸での天体の極と本初子午線、母惑星からの衛星の位置を返します。[自分の three.js シーンで使う](in-your-own-scene.md)を参照してください。

## 0.3 から 0.4 へ

書いたコードへの変更は要りません。0.4 では `embedCode(options, kind, settings)` と `embedCredit(options)` が加わりました。天体をページに置くコードを書き出す関数で（`EMBED_KINDS`：`html`、`module`、`react`、`vue`、`angular`、`svelte`、`iframe`）、kazoku-ui を 0.11 に更新しました。共有の視点コントロールを使っているなら、天体を引き離すと「中央」ボタンが現れ、移動では天体の4分の1が見えたままになります。

```ts
import { EMBED_KINDS, embedCode } from "@johnmorrisdotca/wakusei-planets";

console.log(EMBED_KINDS.join(", "));
console.log(embedCode({ body: "mars", look: "line", size: 240 }, "html").split("\n")[0]);
```

## 0.3.0 から 0.3.1 へ

- **地球はどの見た目でも描かれます。** 以前、陰影つきと地図つきの見た目では、地球は chikyu-earth 自身のライブ要素に渡され、何も映らなくなっていました。今はこのパッケージがほかの天体と同じように、NASA の Blue Marble の画像から描きます。何も映らない地球を避けるための回避策を入れていたなら、外してください。
- **「大きさを合わせる」** は並べた図になりました。すべての天体を同じ縮尺で並べ、小さすぎる天体には線でつないだ拡大図が付きます。新しい属性 `span-km` は、絵の半分の幅をキロメートルで指定します。
- **どの衛星も `body` に指定できます。** `body="io"` はどの見た目でも動きます。
- **天体をビューの外へドラッグで出せなくなりました。** 天体の4分の1は必ず見えたままで、「全体」ボタンで中央に戻ります。

## 0.2 から 0.3.0 へ

- **上へのドラッグで、表面が上へ動くようになりました。** 以前は下へ動いていました。ビューを自分で操作していて、合わせるために傾きの符号を逆にしていたなら、外してください。
- **月が `/all` に入りました。** 以前は抜けていて、月は素朴な球として描かれていました。
- **地図つきの衛星**：9つの衛星に地図が付き、地図つきの見た目の土星の輪は、カッシーニの画像になりました。
- **パッケージの画像が 0.53 MB から 1.31 MB に増えました。** 画像を自分で配信しているなら、新しい画像をコピーしてください。

## 0.1 から 0.2.0 へ

0.2 では `look="painted"` が加わりました。公有の画像による惑星と太陽の実際の表面地図で、最初は小さい画像を使い、拡大すると鮮明なものを取得します（自分で配信するなら `texture-far-base`）。画像の読み込みに失敗しても、陰影つきの見た目は描かれたままです。

## 0.1.0

最初のリリースです。線画、陰影つきの絵、日時に合わせた空を備え、WebGL コンテキストはページにつきひとつです。陰影つきの各天体は、それぞれ任意のエントリーポイントです。変更は要りません。

## アップグレードの前に

1. 今のバージョンと新しいバージョンの間の CHANGELOG を読みます。
2. ページをブラウザーで動かして確かめます。陰影つきの天体には `three`（任意のピア依存、`>=0.160.0`）と、その天体のエントリーポイントか `/all` が必要です。
3. 埋め込みコードを保存しているなら、書き直してください。`embedCode` は、それを作ったときのパッケージのバージョンを書き込みます。
