位置は NASA の JPL Horizons と比べて確かめています。Horizons は天体の位置の基準になるサービスです。`test/accuracy.test.ts` が、すべての惑星、月、衛星を、いくつかの日付で Horizons と比べます。下の限度より離れた天体が一つでもあると、テストは失敗します。表の数字は、それらの日付のうち一番悪かった値です。距離ではなく向きの違いで、惑星は太陽から見た角度、衛星は惑星から見た角度です。

絵として見るときは、衛星の軌道上の 1度は、画面で見る衛星の円盤の幅くらいです。1分角は、1ピクセルの何分の一かです。

## 惑星

水星から海王星は、VSOP87B の級数 (Bretagnon と Francou、IMCCE) から作っています。大事な項だけに短くして (全部で 35,080 項のうち 991 項)、地球時で計算します。地球時は、この理論が書かれている時刻系で、時計の UTC に閏秒と 32.184 秒を足したものです。VSOP87 にない冥王星は、JPL の近似ケプラー要素 (1800年から2050年用) です。1800年から2050年の5つの日付で確かめました。

| 天体 | 一番悪かった値 | 限度 |
|---|---|---|
| 水星 | 2.3″ | 3.5″ |
| 金星 | 0.5″ | 1″ |
| 地球 | 1.5″ | 2.2″ |
| 火星 | 1.4″ | 2.2″ |
| 木星 | 1.9″ | 2.8″ |
| 土星 | 3.7″ | 5.6″ |
| 天王星 | 3.8″ | 5.8″ |
| 海王星 | 3.3″ | 5″ |
| 冥王星 | 39″ | 60″ |

1秒角は 1度の 3600分の1 です。冥王星が一番ゆるいのは、VSOP87 にないからです。冥王星用の表を作る予定です。短くした級数は、1750年から2250年の間で有効で、それより外ではゆっくり悪くなります。1972年より前は、UTC から地球時への換算に、Espenak と Meeus (NASA) の式の ΔT を使い、1972年からは正確な値を使います。

## 月と衛星

月は Meeus の級数の主な項です。ほかの衛星の軌道は、1950年から2050年の Horizons の位置と速度に合わせています。軌道面を一つ決め、平均経度は一定の速さで進み、近点と昇交点は一定の速さで回る、という形です。一定の速さだけでは足りない衛星には、もう一つ項があります。軌道が縮んでいるフォボスには加速があり、たがいに引き合うミマスとテティスは、約70年かけて行ったり来たりします。1900年から2100年の7つの日付で確かめたので、合わせた期間の前後50年ずつが表に入っています。

| 天体 | 一番悪かった値 | 限度 |
|---|---|---|
| 月 | 0.21° | 0.3° |
| フォボス | 0.57° | 0.9° |
| ダイモス | 0.32° | 0.5° |
| イオ | 0.08° | 0.15° |
| エウロパ | 0.09° | 0.15° |
| ガニメデ | 0.21° | 0.3° |
| カリスト | 0.07° | 0.12° |
| ミマス | 1.07° | 1.6° |
| エンケラドゥス | 0.42° | 0.65° |
| テティス | 0.22° | 0.35° |
| ディオネ | 0.08° | 0.15° |
| レア | 0.09° | 0.15° |
| タイタン | 0.05° | 0.1° |
| イアペトゥス | 0.23° | 0.35° |
| ミランダ | 1.76° | 2.7° |
| アリエル | 0.38° | 0.6° |
| ウンブリエル | 0.14° | 0.25° |
| タイタニア | 0.40° | 0.6° |
| オベロン | 0.38° | 0.6° |
| トリトン | 0.03° | 0.1° |
| ネレイド | 6.05° | 9° |
| プロテウス | 0.13° | 0.2° |
| カロン | 0.02° | 0.05° |
| ニクス | 1.93° | 3° |
| ヒドラ | 1.54° | 2.4° |

- **ネレイド**が一番ゆるいのは、軌道がとても細長い (離心率 0.75) からです。一番近い所の近くでは、時刻の小さなずれが大きな角度になります。
- **ニクスとヒドラ**は、二つが回っている冥王星系の重心から測っています。冥王星の中心は重心から約 2,000 km 離れているので、冥王星の中心から見ると、最大で約 2.5° さらにずれることがあります。
- **ミランダ**と**ミマス**は、ふつうの衛星の中では一番ゆるいものです。どちらも、この方法では表せない小さな揺れがあります。
- 冥王星以外の準惑星の衛星 (エリス、ハウメア、マケマケ、オルクス、クワオアなど) は、`src/data/dwarf.ts` に書いた論文から作っていて、この確認には入っていません。

## 何に使えるか

衛星は、軌道上で 1度か 2度の範囲で正しい場所に描かれます。絵、図、空の話には十分です。望遠鏡を向けたり飛行計画を立てたりする暦としては使えません。その場合は JPL Horizons そのものを使ってください。

## 自分で確かめる

`pnpm test` で精度のテストが動きます。`python3 -I scripts/fetch-horizons-reference.py` は Horizons の位置をもう一度取り直して `test/data/horizons.json` に書き、`python3 -I scripts/make-moon-data.py` は衛星を合わせ直して `src/data/orbits.ts` に書きます。どちらもネットワークが必要で、テストの中では動きません。
